# 社労士事務所サイト 広告規制 調査メモ v1（2026-11-07）

**結論**：社労士法に広告を直接規制する条文はなく、規律の実体は**連合会会則 第43条の3・第43条の4**（誇大・虚偽広告の禁止ほか）と法16条（信用失墜行為）。「業務広告に関する指針」は検索では**発見できず**（存在・現行性は未確認）。京都会の会則・広告規程はオンライン未発見。
